# Wallet Watchlist

Take-home for a frontend engineer (JavaScript).

## Start here

You are on **`main`**.

**Check out `assessment` to get the assignment:**

```bash
git checkout assessment
```

Then open **`assessment.md`** and follow it.

## What is in the codebase

- `src/lib/watchlist-store.js` - watchlist and treasury balance
- `src/app/index.html` - watchlist page
- `src/app/watchlist-app.js` - UI behavior
- `src/app/watchlist-app.css` - page styles
